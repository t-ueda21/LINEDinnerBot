# LINE 晩ごはん Bot 要件定義書

> 家族が LINE で夕食をテキストや写真から記録し、「明日の献立」で履歴に基づく候補を受け取れる。写真から読み取った料理名は投稿者が確認してから保存する。定時配信は希望と無料枠に応じて有効にする。OpenAI Platform の API キーは追加支出なしで利用できる条件を確認してから有効にする。AI 停止中もテキスト記録・履歴・簡易提案は使える。

## 品質要件・制約（補足）

| 要件 ID・項目名 | 品質特性・制約 | 適用条件 | 目標値・判定方法 | 根拠・参照先 |

| NFR-01 利用境界 | アクセス権限と秘密管理 | 全イベント・外部呼び出し | 署名検証前の加工・処理を避ける。未許可グループ、個別トーク、無効状態からの操作は保存・送信なし。API キーと LINE の秘密情報はサーバー側で保持。 | 調査 L1・L4、AC-01・AC-02 |
| NFR-01 データ最小化 | 通常会話・個人情報を分析対象から外す | グループの投稿・ログ・API | 通常会話は永続化しない。献立提案に送るのは料理名・集計・対象日の情報のみ。識別情報を含む記入は AI への送信対象から外す。写真認識は本人指定の画像から位置情報などのメタデータを除去して送る。除去できなければ送信しない。写真のバイナリ・公開 URL・API 本文は永続化しない。どちらの API 呼び出しも LINE ID・表示名・メッセージ原文を送らず、`store:false`、外部ツールなしで行う。 | 調査 O4・O5、AC-13・AC-20 |
| NFR-02 費用抑止 | 無料枠と従量課金 | API 有効化・通知送信 | 本番初期値は AI 無効。クレジット限定等の確認まで有効化しない。献立提案は翌日の対象日ごとに1試行、写真認識はグループの食事日ごとに1試行とし、各機能とも JST 月31回までの初期案とする。試行には失敗・タイムアウトも含む。入力・出力上限を設定し、枯渇時は有償経路へ自動切替しない。プッシュは LINE の残量と人数を送信直前に照合する。 | 調査 L3・O3・O5、AC-09・AC-11・AC-14・AC-18 |
| NFR-03 整合性 | 再送・同時実行 | LINE Webhook、AI、定時配信 | 再送識別子が同じ操作は1回分だけ適用。登録元の取消が先着しても復活させない。AI の失敗時は明示した簡易提案に切り替え、同じ対象日の API 呼び出しを重ねない。プッシュの再試行は同じ送信内容・キーで重複を避ける。 | 調査 L4、AC-04・AC-06・AC-10・AC-12 |
| NFR-04 応答時間 | Bot 受信から応答送信開始まで | テスト用グループ、正常な LINE と DB | 記録・履歴は5秒以内を目標とする。手動提案では AI 待ちを最大15秒で打ち切り、30秒以内に応答を送信開始する。期限切れ時はプッシュへ切り替えず、次の手動操作で取得できる。 | 調査 L4、AC-03・AC-07・AC-10 |
| NFR-05 データ保持と復旧 | 記録を維持し削除を反映 | 保存・復旧・提供終了 | 提案値として記録は365暦日保持、削除・期限切れは稼働 DB と次回の履歴・提案から外す。バックアップは設定した保持期限で失効。復旧は非公開環境で削除済み・期限外を確認してから再開する。 | AC-06・AC-15 |
